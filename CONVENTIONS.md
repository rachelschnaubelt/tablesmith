# Site conventions

## Casing

| Element      | Casing        |
| ------------ | ------------- |
| Headings     | Sentence case |
| Buttons      | Lower case    |
| CTAs         | Lower case    |
| Placeholders | Sentence case |
| Checkboxes   | Sentence case |

## CTAs
- Unless the CTA is the trigger for a modal, link, or menu, the first word should always be a verb
- If the CTA is the trigger for a menu, it should be clear that it will open a menu
- If the CTA is for a modal or link, it should prefer to use verbs, but can use other words so long as intent is clear
